# RadarJarbis Bot 🤖

O **RadarJarbis** é o motor de automação exclusivo do ecossistema de afiliados `@noradardojarbis`. Ele foi projetado para operar com o framework Antigravity da Google e ser hospedado de forma eficiente em uma microinstância no Google Cloud Platform (GCP).

## 🚀 Como Iniciar

1. Clone o repositório localmente no seu PC.
2. Copie o arquivo `config/.env.example` para `config/.env` e preencha suas credenciais privadas:
   ```bash
   cp config/.env.example config/.env
